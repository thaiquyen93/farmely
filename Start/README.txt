HUONG DAN SU DUNG CAC FILE TRONG THU MUC START:

   - Chi can double-click vao file nay!

   - Tu dong khoi chay 10 Backend Microservices va Frontend (Vite).

   - Double-click khi ban muon tat toan bo cac tien trinh cua Farmely.

3. Restart-Farmely.bat
   - Double-click de tat roi bat lai toan bo he thong.

4. Import-Sample-Database.bat
   - Dung khi ban can reset hoac nap lai toan bo 26 bang va du lieu mau tu file Database\farmely_full_database.sql.
